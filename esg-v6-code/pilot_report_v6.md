## 1. 匹配程度（分字段，不合成总分）

每张图算：主体匹配率、项目/奖项匹配率、时间匹配率（只算年+月，只对上年份不算）、数值匹配率（试点图无数值，全部记 NA）、CLIP 本地 top 分（照片）、限定保留率（试点本地无限定词，全部记 NA）。

## 2. 是否不匹配（规则，不靠总分过线）

- 本地为空 → 不匹配（无支撑）
- 硬字段（主体/项目）一个都没出现 → 不匹配（无支撑）
- 硬字段有命中 → 一致（主题级/字段级）

结果：**23 张里一致 4 张，不匹配 19 张**，和 v5 的结论一致。

一致的 4 张：
- G0002-2 西安高新医院：命中“西安、高新”（本地有“西安高新医院于2002年6月开诊”）
- G0066-1 培训听讲：命中“集体、培训”
- G0066-2 集体宣誓：命中“集体宣誓、宣誓”
- G0002-1 建筑外景+标语：命中“国际、医学”——**只靠通用词**，和 v5 的“主题一致（仅通用词支撑）”是同一回事，不要把它读成强支撑。

不匹配的 19 张：G0004 16 张证书（本地 0 段），G0001 航拍（本地 0 段），G0021、G0040（本地有文字、硬字段 0 命中）。

## 3. 聚类（只聚 19 张不匹配的）

特征 = 现象特征（图类型、本地段数、实体率、项目率、时间率、CLIP 分），不含类型标签。
k=2 轮廓 0.907，k=3 轮廓 0.928，k=4 轮廓 0.842，选 k=3。层次聚类成员与 KMeans 一致。

- **簇 0，16 张**：全是 G0004 证书，本地 0 段、实体率 0、项目率 0。聚完命名：**无本地上下文的证书宣称**。
- **簇 1，2 张**：G0021、G0040，本地 6–7 段、硬字段 0 命中、CLIP 0.471 / 0.384。聚完命名：**本地有文字但与图片无关的照片**。
- **簇 2，1 张**：G0001 航拍，本地 0 段。聚完命名：**无本地上下文的照片**（样本大了这一簇会长大，现在只有 1 张，名字先不急着定）。

## 4. 这次重跑暴露的问题（实话）

1. **分词太糙。** 核心词用二字滑窗找的，分母被撑大了（有的证书项目分母到 47），还冒出无意义的词（“安高、新医、体宣”）和通用词（“国际、医学、人员”）。二值结论（一致/不匹配）这次没受影响，但匹配率本身不干净。正式跑要用 distinctive 全词组 + 一份人工定的核心词表（培训、宣誓、高新医院……），不要用滑窗。
2. **G0002-1 的“一致”只靠通用词。** 不要把它和 G0066-2 的“集体宣誓”命中混为一谈，前者弱、后者强。正式版要把“仅通用词支撑”单独记一档。
3. **试点里还是没有值错、时间错、限定丢了的例子。** 所以聚类只能分出上面这三簇，分不出值错、时间错那些细簇。要等大样本、那些现象都出现了才能聚出来。
4. **数值、限定两项在试点里全是 NA。** 不是方法不要这两项，是试点这批图没有这些字段。
